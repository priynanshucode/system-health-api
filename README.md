# 🖥️ System Health Monitor API

A simple **FastAPI** project that monitors system health by reporting CPU, memory, and disk usage in real time.

---

## 🚀 Features
- FastAPI-based lightweight backend  
- `/health` endpoint returns live system statistics (CPU, memory, disk)  
- Uses **psutil** to read system performance data  
- Auto-generated API documentation with Swagger UI and ReDoc  

---

## 🧩 Tech Stack
- **Python 3**
- **FastAPI**
- **Uvicorn**
- **psutil**
